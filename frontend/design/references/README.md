# 后续 UI 设计图放置位置

后续设计稿或参考截图可以放在此目录，建议命名：

- `login.png`：登录与注册。
- `products.png`：产品管理。
- `product-detail.png`：产品资料详情。
- `cases.png`：独立案例库与分析详情。
- `generate.png`：内容生成。
- `review.png`：审核发布。
- `feedback.png`：数据反馈、观测历史与运营经验。
- `settings.png`：模型、Prompt 和规则设置。

这里存放设计参考，不会被打包到网页中。运行时 Logo、插图、占位图放在 `public/ui/`。
页面按组件重做，API 和工作流逻辑可以继续复用，不将整张设计截图作为页面背景实现交互。
