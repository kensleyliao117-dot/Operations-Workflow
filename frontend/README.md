# Operations Workflow 前端

Vue 3 + Vite，桌面优先的简洁工作台。采用左侧栏与右侧单一主界面，保持第一版浅绿、灰白和深绿色配色；侧栏可隐藏，桌面展开偏好刷新后保留，手机使用遮罩抽屉。默认直接连接现有 FastAPI，不包含模拟业务数据。

## 启动

Windows 首次安装完成后，可双击项目根目录 `start_all.cmd` 同时启动前后端；也可分别双击 `start_backend.cmd`、`start_frontend.cmd`。缺少环境或依赖时会显示错误提示，首次部署见 [根目录说明](../README.md)。

后端在项目根目录启动：

```powershell
python run_local.py
```

前端：

```powershell
cd frontend
npm ci
npm run dev
```

浏览器访问 `http://127.0.0.1:5173`。API 默认 `http://127.0.0.1:8000`。
构建环境使用 Node 24；项目的 npm 12 需要 Node 22.22.2+ / 24.15+。

本机 Node 尚未加入 PATH 时，也可使用脚本查找现有 Node（不安装全局软件）：

```powershell
.\frontend\dev.ps1 install
.\frontend\dev.ps1 dev
```

`dev.ps1` 也支持 `build`、`test`、`preview`。依赖已安装时无需再次 install。
脚本的依赖、下载缓存放在项目下，运行时代码不依赖本机工具的绝对安装路径。

将 `.env.example` 复制为 `.env.local` 可修改 API 和静态资源根地址。`VITE_*` 会进入前端构建，仅用于公开配置；用户模型密钥通过认证接口加密保存到后端数据库，不写入前端环境变量。
本机采集和发布要求本机直连，Vite 没有设置 API 代理，后端仍校验回环地址、Origin 和 JWT。
修改前端端口时，也需要调整后端 `CORS_ORIGINS`。

## 页面和接口

| 页面             | 已接入能力                                                                                                                 |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Login / Register | 注册、登录、当前会话验证、退出、401 清理                                                                                   |
| Products         | `/products` 产品列表；点击进入 `/products/:id` 资料详情，支持创建编辑删除、批量上传下载删除、RAG 入库与重试                |
| Cases            | `/cases` 独立案例库：链接采集、已存案例搜索、AI 分析、反馈修订和版本对比                                                   |
| Generate         | `/generate` 选择产品、输入需求、弹窗选择已有分析版本、Prompt 偏好、任务创建与 LangGraph 启动查询重试                       |
| Review           | 内容版本、本机编辑草稿、保存并提交审核、规则复查、人工审核恢复、配图生成与鉴权预览、发布确认与结果核实、真实指标及经验处理 |
| Settings         | `/settings` 独立设置页：分析模型、Prompt 模板、平台规则，使用二级分类切换                                                  |
| Feedback         | `/feedback` 已发布作品、多次观测、发布后观察窗口、后台数据补录、证据选择与运营经验版本                                     |

创作页只选择已有的案例分析，不嵌入完整采集和分析管理界面。审核页的文案与配图、风险与审核、发布与反馈纵向排列，顶部快捷链接定位到对应区域。产品列表和资料详情分别展示，避免主界面再分成多列。任务历史和临时参考选择使用弹窗，生成完成后配置默认收起。右下角提示不遮挡顶部导航。

## 数据反馈与运营经验

“数据反馈”位于左侧独立入口 `/feedback`。同一作品可反复采集，保留每次观测时间、来源和“发布后多久”的观察窗口，未知发布时间明确提示待核实。前端默认从创作中心采集可取得的指标，曝光、点击、转化等未取得的数据可录入真实后台数值；浏览量与曝光量分开，未知指标不填零。选择历史快照后明确触发 AI 提炼运营经验，可查看版本及证据、启用或停用；后续生成继续通过原经验检索使用有效版本。这属于经验积累，不直接训练模型参数。接口与口径说明见 [`docs/memory.md`](../docs/memory.md)。

## 素材与配置维护

创建任务时可选仅文案、仅图片或两者组合。风险仅作提示，不阻止保存、人工审核和发布；已有同一版本可直接提交审核，无需伪造修改。案例库支持手动新增、修改和删除，Prompt 与规则支持增删改，公共参考规则的修改仅影响当前账号。

审核页可下载文案和图片，在平台补充另一部分后选择“自行发布并登记结果”。实际作品仍绑定已审核版本、平台账号和作品链接，可记录最终文案及外部素材说明。自动发布继续使用完整的已保存素材。见 [素材生成与人工决定](../docs/flexible_materials.md)。

专用 Chrome 可双击项目根目录 `start_chrome.cmd` 启动，使用本机 `storage/chrome-profile/`，参见 [采集说明](../docs/collectors.md)。

「内容生成 → 任务历史」支持确认后彻底删除任务，同时清理内容、图片、审核、发布、反馈、经验及工作流进度。旧版已移除的任务也可继续清理。生成或发布中的任务暂不可删除，发布结果未知时需先核实。删除失败可重试，删除当前任务后回到新建状态。

数据反馈页和审核页的反馈面板支持删除整篇反馈、单次观测或单个经验版本。删除观测会同步移除引用它的分析与经验；删除整篇反馈保留发布记录与平台真实帖子。产品关联任务和上传资料全部删除后，可以删除产品。

## 平台与分析模型

顶部“目标平台”仅提供“小红书”和“其他平台 · 待接入”两个入口，不预设未来接入的具体平台。平台能力由后端 `GET /platforms` 返回；目前仅小红书接入完整流程。“其他平台”用于预留配置，不能启动生成或调用小红书采集、发布接口。
任务、Prompt、规则和未提交的生成配置按平台区分；产品知识资料可在同一账号下供不同平台使用。切换平台不会改变已有任务所属平台。

新增平台时在 `services/platforms.py` 声明入口和能力，接入对应工作流、校验器与发布器，并在 `src/config/platform_adapters.js` 注册采集和发布 UI。缺少适配器时不会回退到小红书。

左侧“设置 → 模型连接”或案例中的“添加或管理分析模型”支持新增、编辑、启停和删除配置。供应商名称自由填写，输入 API URL、API Key 和模型 ID 后保存；支持公网 HTTPS 的 Chat Completions 兼容接口，不限制供应商品牌。非兼容协议需要独立适配器。

配置按 JWT 用户隔离，API Key 在后端加密，不回显也不写入浏览器存储。编辑留空保留原密钥，更换 URL 必须重新填写密钥。保存不会调用模型；“测试连接”执行简短模型请求，可能产生少量费用。“凭据已配置”不代表已测试远程服务可用。

模型连接分为文本、Embedding、生图三类，分别支持添加、编辑和删除。文本默认模型用于案例分析、文案生成、规则检查、图片 Prompt 和运营经验提炼；Embedding 默认连接用于入库与检索，修改接口、模型或维度后需重新入库；生图可使用默认连接或单次指定连接，并按连接选择尺寸。密钥按用户加密保存，不回显、不写入共享 `.env`。未配置账号默认连接时兼容部署端环境变量，历史记录保留。

本次增加模型连接字段迁移，部署时执行 `python -m alembic upgrade head`。部署密钥及备份说明见 [模型连接](../docs/model_connections.md)。

每次请求由后端鉴权和隔离用户，前端不提交 `user_id`。
JWT 使用标签页内的 `sessionStorage`；刷新后由 `/auth/me` 验证，不把 JWT 写入 URL 或持久 `localStorage`。
内容编辑草稿使用用户 ID + Content ID + 版本隔离的本机存储，退出时清理当前账号的本机草稿和请求键。
本机草稿不是数据库版本：用户明确保存时才创建新 Content，提交审核后才能审核和发布。

## 更换 UI

- 设计参考图：[`design/references/`](design/references/README.md)。
- 可替换运行时图片：[`public/ui/`](public/ui/README.md)。
- 图片语义路径及产品名称：[`src/config/ui.js`](src/config/ui.js)。
- 颜色、字体、圆角、间距：[`src/styles/tokens.css`](src/styles/tokens.css)。
- 通用表单、按钮、面板：`src/styles/base.css`。
- 页面布局与主题覆盖：`src/styles/theme.css`。
- 可替换 Vue 组件：`src/components/`，业务页面位于 `src/views/`。
- 后端接口封装：`src/api/`，不与主题、品牌素材绑定。

替换同名素材即可保留引用。改变素材格式时集中改 `ui.js`，布局或组件风格改变不需要重写 API。
静态素材的更改在开发环境即时生效；生产环境请重新构建或替换 `dist/ui/` 对应公开文件。

## 状态与操作边界

- 采集器目前支持完整帖子链接或已打开详情页，不承诺尚未实现的关键词自动搜索。
- 上传和 RAG 入库分别显示，入库失败不会显示为就绪。
- 当前没有百分比进度接口，长任务显示真实状态和处理中提示，不显示虚构百分比。
- 工作流、AI 配图、审核和发布调用均不自动重试写请求。HTTP 超时后先刷新任务或记录。
- 配图和运营分析由用户明确触发，运行时可能产生模型费用。
- 审核通过与发布分开确认；发布账号必须明确选择，默认“仅自己可见”。后端仍验证最新审核版本、素材和实际账号。
- 发布结果不明时只能核实并登记实际结果；不能直接盲目重发。失败后的新尝试保留旧记录。
- 经验只作为下一轮参考，不覆盖人工 Prompt，不作为产品参数依据。
- Chrome 启动和登录继续按 `../docs/collectors.md` 操作。

## 验证

```powershell
npm run build
npm test
# 从项目根目录执行；先启动 Vite。使用本机现有 Chrome，无需安装测试浏览器。
python -m unittest discover -s frontend/tests -p browser_smoke.py -v
python -m unittest discover -s tests -p test_frontend_support.py -v
```

浏览器测试使用独立无头 Chrome 和 API 契约替身，所有测试请求被拦截，不调用真实模型、不写生产数据库、不发送帖子。
测试覆盖人工保存、审核、发布确认、结果不明恢复、指标及经验展示、草稿恢复、会话退出、上传/入库区分、平台配置隔离和模型新增切换启停删除，也验证第一版色值、独立页面、主区域宽度、纵向审核布局、侧栏偏好、参考选择不触发提交和未上传文件离开提示。
测试截图保存在被 Git 忽略的 `storage/frontend-tests/`。真实平台自动发布仍需按明确账号和审核版本单独验收。
