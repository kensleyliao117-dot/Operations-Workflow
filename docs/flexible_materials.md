# 素材生成与人工决定

风险检查提供原因、证据和建议，不决定内容能否保存、提交人工审核或发布。`risk_detected`、`error`、`incomplete` 均保留原状态供人工参考。人工审核仍绑定当前用户、Task、最新 Content ID 和版本；发布还需明确账号及可见范围。

## 按需生成

`POST /tasks/{id}/workflow/start` 接受 `output_mode`：

| 值 | 行为 |
| --- | --- |
| `text` | 仅生成文案，不调用生图接口 |
| `images` | 仅根据产品资料和需求生成图片，不生成营销文案 |
| `text_images` | 生成文案后生成配图 |

图片参数为 `image_style_requirement`、`image_count`、`image_size`。文案与图片均保存 Content 版本；图片步骤失败保留已经保存的文案或图片需求，重试复用已落库步骤，避免重复生图。图片及文案可在审核页分别下载。

生成仅文案时，不要求关联图片才能审核。生成仅图片时，标题、正文可以留空，不自动填入占位营销文案。自动图文发布使用完整的已保存素材；部分素材在平台补充时，选择“自行发布并登记结果”，不调用自动发布按钮。

发布结果登记继续绑定实际账号、Content 版本、作品 ID 和链接。可填写 `final_content`（最终标题、正文、标签）与 `external_materials_note`，保存在发布记录并同步经验库；平台补充的图片未读取时，不把工作流内图片数当成作品实际总图片数。

## 资源维护

- 案例：新增、修改、删除；删除后从当前用户的列表和分析选择中移除，保留历史引用。重新采集相同链接可恢复案例。
- Prompt：新增、修改、删除；删除后不参与后续选择，历史生成版本保留。
- 自定义规则：新增、修改、删除，按用户隔离。
- 平台参考规则：可修改或移除，公共参考规则的变更保存在当前用户的覆盖配置中，不影响其他用户；用户新建的平台规则仅属于本人。

删除不会改写已生成 Content 的引用快照和历史风险检查记录。旧任务重新生成时若引用已删除配置，需要重新选择可用配置。

## 审核操作

有修改时，“保存并提交审核”先新增版本，再使用 `submit_changes`。已保存的新版本可直接提交；同一版本无需伪造修改，使用 `submit_review` 提交审核。已经被人工驳回的原版本仍需要修改后再提交。`recheck` 是可选的重新风险检查，不是发布前置条件。

Chrome 连接可双击根目录 `start_chrome.cmd`；图形界面、用户资料与业务数据仍在本机保存。
